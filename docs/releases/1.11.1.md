# SynapseJS 1.11.1 — vendor bundle freshness, hydration URL sync and interactive client fixes

## Highlights

- **Vendor bundle freshness.** `_vendor.js` is rebuilt when the client entry, the client components
  or the application manifest becomes newer than the bundle. The vendor bundle exports every client
  primitive (`Modal`, `Drawer`, `Tabs`, `ToastProvider`, `useToast`, `SynapseProvider`, `useAction`,
  `rpcCall`, and the existing form/table primitives).
- **Hydration URL synchronization.** The SSR shell exposes `__SYNAPSE_URL__`; the generated client
  entry passes the current URL to the root layout, domain layout and `SynapseProvider`. Active
  navlinks no longer mismatch between SSR and hydration.
- **Interactive client primitives.** `Modal` and `Drawer` carry explicit fixed-position styles;
  `DropdownMenu` uses a `role="button"` wrapper (avoiding nested `<button>` HTML) and toggles with
  Enter/Space. Tabs switch panels on click.
- **Deterministic showcase CSS.** Tailwind is pinned to `3.4.19`; the generated showcase stylesheet
  is reproducible and the new `showcase css deterministic` gate fails if a build changes it.
- **MCP seed honesty.** `synapse_generate_seed` returns `FAIL` with `SEED_INSERT_FAILED` when no row
  can be inserted, instead of reporting a false PASS.
- **Regression coverage.** Vendor rebuild/exports, interactive Modal/Drawer/Dropdown/Tabs,
  `useUpload` progress/abort/validation, client route params, real HTTP streaming, OAuth profile
  normalization, and the new MCP `test_slice`/`generate_seed` tools.

- `bash scripts/run-gates.sh`: 22/22 gates, including the deterministic showcase CSS gate.
- `bun run test:all`, `bun run check`, `bun run check:template`, `bun run lint`, `bun run split`,
  `bun run docs:check`, `bun run coverage:check`, the live e2e suite and the publish rehearsal are
  the release gates.
- `release-evidence/1.11.1.md` records the exact commands, exit codes and commit; it is replayed by
  `scripts/verify-release-evidence.ts`.

## Known limits

- In-memory SSR micro-cache, token bucket rate limiter, and event hub state remain per-process.
- TypeScript 7 is guarded with `COMPILER_API_UNAVAILABLE`; the full migration remains planned for a
  later minor.
- PostgreSQL cron parity is not implemented; the engine fails explicitly with
  `CRON_UNSUPPORTED_ENGINE`.
- No external adopters registered: ratings reflect verifiable test evidence, not production telemetry.

# SynapseJS 1.10.0 — scheduled jobs, portable aggregation, RBAC permissions and UI integration

## Highlights

- **Query engine.** `GROUP BY`, `DISTINCT`, `HAVING`, `count`, `exists` and `aggregate` share one
  contract across SQLite and PostgreSQL. A `HAVING` condition that names an aggregation alias is
  compiled to the aggregate expression, so PostgreSQL receives portable SQL. `exists` stops at the
  first matching row.
- **Scheduled jobs.** Cron follows POSIX/Vixie semantics (day-of-month OR day-of-week when both are
  restricted), validates ranges/steps, accepts Sunday as `0` or `7`, and rejects names/`L`/`W`/`#`/`?`
  with a clear error. `runAt` is honored, cron payloads can use a factory, and DLQ inspection/retry is
  available. The PostgreSQL queue refuses cron with `CRON_UNSUPPORTED_ENGINE` (parity is scheduled for
  1.11).
- **Sessions and OAuth.** Signed tokens carry bounded `permissions`; legacy tokens remain valid. The
  admin/superadmin bypass is configurable through `SYNAPSE_RBAC_ADMIN_BYPASS`. OAuth exchange has a
  timeout/abort, and `generateOAuthState`/`verifyOAuthState` provide constant-time state validation.
- **UI and assets.** The local CSS bundle is built by `synapse build`, `dev` and `start`; no theme is
  injected when the application has no stylesheet. `SliceErrorBoundary` wraps the client slice view by
  default. SPA morphing preserves focus, value, checked, selected and scroll state.
- **Scaffolding.** `new-domain` is transactional and returns `PARTIAL_WRITE` with the remaining paths
  when cleanup is unsafe. `WARN_LARGE_SLICE` warns above 500 lines without failing the split.
- **TypeScript.** The compiler dependency is pinned to `~5.9.3`; a resolved compiler without the
  in-process API fails with `COMPILER_API_UNAVAILABLE` and names the detected version. TypeScript 7
  migration is scheduled for 1.11.

## Breaking changes and migration

1. **Cron day fields.** When day-of-month and day-of-week are both restricted, the schedule is the OR
   of the two, not the intersection. *Migration:* use `*` in one of the fields or split the schedule
   into two jobs.
2. **`HAVING` aliases.** A condition that references only an output alias is compiled to the aggregate
   expression (or rejected if it cannot be mapped). *Migration:* use the structured
   `{ fn, column, op, value }` condition or repeat the aggregate expression.
3. **`new-domain` partial failure.** A partial scaffolding operation now returns `Err` and removes the
   files it created; callers that treated a partial `Ok` as success must handle the error.
4. **Error boundary default.** Client slice renders are wrapped in `SliceErrorBoundary` by default.
   *Migration:* pass `errorBoundary={false}` to `SynapseProvider` to restore the previous behavior.

  `scripts/verify-release-evidence.ts`.

## Known limits

- PostgreSQL cron parity is not implemented in 1.10; the engine fails explicitly with
  `CRON_UNSUPPORTED_ENGINE`.
- TypeScript 7 is not supported by the in-process compiler layer; the guard names the
  incompatibility and the migration is planned for 1.11.
- The CSS pipeline bundles an application stylesheet; it is not a Tailwind compiler.
- Rate limiting, the SSR cache and the event hub remain per-process.

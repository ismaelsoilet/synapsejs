# SynapseJS Starter App ⚡

Aplicação construída com **SynapseJS** — o framework fullstack centrado na máquina e nativo para agentes de inteligência artificial.

## Comandos Rápidos

```bash
# 1. Iniciar servidor com SSR e auto-migração
bun run dev

# 2. Criar uma nova fatia vertical com 1 comando
bun run new-slice <domain> <name>
# Exemplo: bun run new-slice users register-user

# 3. Testar invariantes com oráculos PBT
bun run test

# 4. Checagem de tipos ultrarrápida para IA
bun run check:fast

# 5. Iniciar servidor MCP local
bun run mcp
```

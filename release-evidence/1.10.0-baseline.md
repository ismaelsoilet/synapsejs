`HAVING` emitted an output alias (PostgreSQL rejects it); the CSS bundle was never built on
first boot; `SliceErrorBoundary` was exported but unused; SPA navigation preserved values but
not focus/checked/scroll; `new-domain` returned Ok on partial failure; permissions were absent
from signed session tokens; `docs-check`/`coverage-check` re-injected `NODE_ENV=development`;
TypeScript 7 removed the in-process compiler API used by eight modules.
